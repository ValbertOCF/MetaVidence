MetaVidence

Meta-analysis without coding

MetaVidence is a free application for conducting meta-analyses without coding. Researchers can import spreadsheets, specify statistical models and export plots and tables. The web application runs R inside the browser through WebAssembly, so study data stay on the user's device. It supports:

  • Pairwise meta-analysis of binary and continuous outcomes
  • Single-arm meta-analysis of proportions and means
  • Meta-analysis of pre-calculated effects, such as hazard ratios
  • Network meta-analysis
  • Diagnostic test accuracy meta-analysis

The development and validation of MetaVidence are described in a preprint that has not yet been peer reviewed.
